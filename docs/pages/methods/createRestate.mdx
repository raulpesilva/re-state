# createReState

Creates a hook bound to a state key. The factory initializes the key with `initialValue` when it is first registered, and the returned hook provides the familiar `[value, setValue]` tuple.

```ts filename="states/counter.ts"
import { createReState } from '@raulpesilva/re-state';

export const useCounter = createReState<number>('counter', 0);
```

```tsx filename="components/Counter.tsx"
import { useCounter } from '../states/counter';

export function Counter() {
  const [count, setCount] = useCounter();

  return (
    <button onClick={() => setCount((previous) => previous + 1)}>
      Count: {count}
    </button>
  );
}
```

Every hook created for the same key shares the same value. If that key is already registered, a later call does not replace its current or initial value. An initializer function is evaluated while the factory initializes a new key.

`createReState` returns a hook, so call the returned function only from a React component or another custom hook.

## API

```ts
function createReState<S>(
  key: string,
  initialValue?: S | ((previous: S) => S)
): () => [
  S,
  (value: S | ((previous: S) => S) | undefined) => void
]
```

| Parameter | Type | Description |
| --- | --- | --- |
| `key` | `string` | Shared state key. |
| `initialValue` | `S \| ((previous: S) => S)` | Value or initializer used when the key is not registered. |

The hook returns the current value and a setter. The setter accepts a value or an updater function that receives the current value.

If no initial value is supplied, the value is `undefined` until something initializes the key.
