# createReStateMethods

Creates the complete set of methods for one state key: a writable hook, a read-only hook, a dispatcher, a getter, and a per-key reset function.

```ts filename="states/muted.ts"
import { createReStateMethods } from '@raulpesilva/re-state';

export const { useMuted, useMutedSelect, dispatchMuted, getMuted, resetMuted } = createReStateMethods<'muted', boolean>(
  'muted',
  false
);
```

```tsx filename="components/MuteButton.tsx"
import { useMuted } from '../states/muted';

export function MuteButton() {
  const [muted, setMuted] = useMuted();

  return <button onClick={() => setMuted((previous) => !previous)}>{muted ? 'Unmute' : 'Mute'}</button>;
}
```

The state is initialized when the factory runs. A later factory call with the same key does not replace an existing current or initial value.

## Generated methods

For a name of `volume`, the returned object contains:

| Method                  | Behavior                                                       |
| ----------------------- | -------------------------------------------------------------- |
| `useVolume()`           | Returns `[value, setValue]` and subscribes to the key.         |
| `useVolumeSelect()`     | Returns the value and subscribes to the key, without a setter. |
| `dispatchVolume(value)` | Replaces or functionally updates the value from anywhere.      |
| `getVolume()`           | Reads the current value synchronously without subscribing.     |
| `resetVolume()`         | Sets only this key to its reset value.                         |

`name` is used verbatim except that its first character is capitalized for generated names. It must be a non-empty string; invalid names throw.

### Custom reset value

Pass `{ value: ... }` as the third argument to register a reset value:

```ts
const { dispatchVolume, resetVolume } = createReStateMethods<'volume', number>('volume', 100, { value: 50 });

dispatchVolume(20);
resetVolume(); // volume is now 50
```

The optional object also updates the baseline used by [resetReState](/methods/resetReState). The generated reset method uses the custom value when it is non-nullish; otherwise it falls back to `initialValue`.

## API

```ts
function createReStateMethods<S extends string = string, V extends any = any>(
  name: S,
  initialValue?: V | ((previous: V) => V),
  valueOfReset?: { value: V }
): ReStateMethods<S, V>;
```

The returned object has names derived from `name`:

```ts
use<Name>(): [V, (value: V | ((previous: V) => V) | undefined) => void]
use<Name>Select(): V
dispatch<Name>(value: V | ((previous: V) => V) | undefined): void
get<Name>(): V
reset<Name>(): void
```

The `initialValue` function is used to initialize a new key. `valueOfReset` is a plain object containing the value used by the generated reset method.
