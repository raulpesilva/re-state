# createReStateSelect

Creates a read-only hook bound to one state key. It returns the current value and subscribes only to that key, so components do not receive a setter.

```ts filename="states/theme.ts"
import { createReState, createReStateDispatch, createReStateSelect } from '@raulpesilva/re-state';

type Theme = 'light' | 'dark';

export const useTheme = createReState<Theme>('theme', 'light');
export const useThemeSelect = createReStateSelect<Theme>('theme');
export const dispatchTheme = createReStateDispatch<Theme>('theme');
```

```tsx filename="components/ThemeLabel.tsx"
import { useThemeSelect } from '../states/theme';

export function ThemeLabel() {
  const theme = useThemeSelect();
  return <p>Current theme: {theme}</p>;
}
```

`createReStateSelect` does not initialize the key. Initialize it with [createReState](/methods/createReState), [useReState](/methods/useReState), a dispatcher, or [setReStateInitialValue](/methods/setReStateInitialValue) before relying on a defined value.

The hook uses the external-store snapshot for the key. React compares that snapshot with `Object.is`; this hook does not apply the shallow equality used by [useReStateSelector](/methods/useReStateSelector). An uninitialized key therefore returns `undefined` at runtime.

## API

```ts
function createReStateSelect<S>(key: string): () => S;
```

| Parameter | Type     | Description                                |
| --------- | -------- | ------------------------------------------ |
| `key`     | `string` | Shared state key to read and subscribe to. |

The returned hook takes no arguments and returns the current value.

## Comparison

| Need                                  | Use                                                   |
| ------------------------------------- | ----------------------------------------------------- |
| Read and write one key in a component | [createReState](/methods/createReState)               |
| Read one key in a component           | `createReStateSelect`                                 |
| Read one key outside React            | [createGetReState](/methods/createGetReState)         |
| Select derived data from several keys | [useReStateSelector](/methods/useReStateSelector)     |
| Get all methods for one key           | [createReStateMethods](/methods/createReStateMethods) |
