# Vite TypeScript example

This example demonstrates both the typed ToDo state and the shared-state `SimpleUsage` flow with React and Vite.

Install dependencies and start the development server:

```sh
pnpm install
pnpm dev
```

The local checks are available through `pnpm format:check`, `pnpm lint`, `pnpm typecheck`, `pnpm test`, and `pnpm build`.
